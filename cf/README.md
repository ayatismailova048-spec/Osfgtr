# Домашние дела (Cloudflare, бесплатно)

Страница, хранилище и уведомления работают на бесплатном тарифе Cloudflare Workers. Сервер не засыпает.

Адрес: https://domashnie-dela.dela-48242f.workers.dev

- Каждый открывает страницу и нажимает своё имя. Родитель нажимает «Я родитель».
- Дети отмечают только свои задания, родитель любые.
- Уведомления: 13:00 (посуда до обеда), 18:00 и 20:00 (что не сделано), сводка родителю в 21:00 по Москве.
- Родитель пишет сообщение ребёнку, и оно приходит уведомлением.

## Файлы
- `src/worker.js` — сервер (хранилище Durable Object с SQLite, push, рассылка по расписанию).
- `public/` — страница. `public/schedule.js` — расписание заданий (из него же собирается PDF).
- `src/assets.js` — файлы страницы, вшитые в сервер. Создаётся командой `node build-assets.mjs`; после любого изменения в `public/` запустите её.
- `wrangler.toml` — настройки.

## Выкладка
```bash
cd cf
npm install
node build-assets.mjs
CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=... npx wrangler deploy
```
