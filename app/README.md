# Домашние дела: сервер с уведомлениями

Страница и сервер в одном приложении (Node.js). Что умеет:

- у каждого человека своя личная ссылка, дети отмечают только свои задания, родители любые;
- родитель пишет сообщение ребёнку, и оно приходит ему уведомлением;
- напоминания детям: 13:00 (посуда до обеда), 18:00 и 20:00 (всё, что не отмечено);
- сводка родителям в 21:00: кто сколько сделал, кого похвалить, с кем поговорить;
- каждый ребёнок выбирает цвет своего имени.

Время для напоминаний считается по часовому поясу из `TZ_NAME` (по умолчанию `Europe/Moscow`).

## Запуск на Render

1. Зайдите на https://render.com и войдите через GitHub. Разрешите Render доступ к репозиторию `Osfgtr`.
2. Нажмите **New → Blueprint**, выберите репозиторий. Render прочитает `render.yaml` в корне.
3. Перед созданием проверьте переменную `PARENTS`: впишите имена родителей через запятую (например `Мама,Папа`).
4. Нажмите **Apply**. Через несколько минут сервис запустится. Его адрес вида `https://domashnie-dela.onrender.com` виден в панели Render.
5. Откройте `https://ВАШ-АДРЕС/admin?key=ADMIN_KEY`. Значение `ADMIN_KEY` лежит в панели Render: **Environment**. На странице будут личные ссылки для всех.
6. Отправьте каждому его ссылку. После первого открытия вход запоминается.
7. Каждый открывает приложение на своём телефоне и нажимает **Включить уведомления**.

На iPhone уведомления работают только если добавить страницу на экран «Домой» (Safari → Поделиться → На экран «Домой») и открывать её оттуда. Нужен iOS 16.4 или новее.

## Важное

- Тариф Render **Starter** платный (около 7 долларов в месяц). Он нужен по двум причинам: бесплатные сервисы засыпают и не отправили бы вечерние уведомления, а без постоянного диска данные пропадали бы при каждом обновлении.
- Ссылка человека работает как пароль. Если ссылка попала не туда, удалите файл `state.json` на диске (все получат новые ссылки, отметки сбросятся) или напишите мне, я добавлю смену ссылки.
- Ветка в `render.yaml` указана `ccr-592f80d4-v1bovu`. После слияния в основную ветку замените её на `main`.

## Локальный запуск

```bash
cd app
npm install
ADMIN_KEY=секрет PARENTS="Мама,Папа" node server.js
```
Личные ссылки печатаются в консоль при запуске.
